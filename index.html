Como compartilhar o app

Cada colega usa a própria versão — os dados ficam salvos apenas no navegador de cada um.

Para os colegas é simples:

Não precisa criar conta, não precisa instalar nada. Só abrir o link abaixo no navegador.

https://vaesquivel.github.io/banco-de-horas/ copiar
Link copiado!
1

Envie o link pelo WhatsApp ou e-mail

Cada colega abre o link no celular ou computador. Na primeira vez o app pede nome, horário e dias habituais de HO.

Os dados ficam salvos só no navegador de cada um — ninguém vê os dados de ninguém.
2

Favorite para acesso rápido

Peça para cada colega salvar nos favoritos: Ctrl+D (Chrome/Edge) ou ⌘+D (Mac).

No celular: "Adicionar à tela inicial" para abrir como app.
3

Importar PDF do banco de horas (opcional)

Quem tiver o PDF do cartão de ponto pode importar na configuração inicial para ver o histórico desde janeiro. Clique em editar para acessar o fluxo de importação a qualquer momento.

Só você precisa saber: o app fica hospedado no GitHub Pages no repositório vaesquivel/banco-de-horas. Para atualizar o app no futuro, basta substituir o index.html lá — todos recebem a nova versão automaticamente.

Importar do RH
PDFs do cartão de ponto

Exporte os PDFs no aplicativo do RH e selecione todos de uma vez aqui (jan, fev, mar…). Dias que você já registrou manualmente são mantidos — o app adiciona só o que falta.

Arraste os PDFs aqui ou toque para selecionar
Pode selecionar vários arquivos de uma vez — e repetir para adicionar mais

Backup de dados

Exporte seus registros para guardar ou comparar. Importe para restaurar em outro dispositivo.

Copie o JSON abaixo. Use para guardar um backup ou para comparar com outro app.

Copiado!
Trocar de aparelho? Toque em "Copiar link p/ celular" e envie o link para você mesma (WhatsApp, e-mail). Ao abrir no outro aparelho, o app pergunta se quer importar tudo — registros, configuração e horários. O link contém seus dados: não compartilhe com outras pessoas.
Para comparar com o app da aba anônima:
Gere o JSON no app correto, depois abra a aba anônima, clique em Backup → Importar e cole o JSON. O app anônimo vai usar seus dados manuais.

Cole o JSON de um backup ou o link de transferência (aquele com #t=…). Isso substituirá todos os registros atuais.
